# Commands

Lists every command you may run, including your game's own module commands,
grouped by module. Pick one to get a form built from its arguments: player
pickers, numbers, durations with presets, choices and text.

Commands that change state ask for confirmation first. The result, with any
listing rows, appears below the form.

These run through the same host dispatcher as the console, so permissions, target
protection, audit and private replies are unchanged. A command you add to your
game appears here without any menu code.
