**0.1.0-rc.1 — unpublished source candidate.** Package identity: `notpointless.chomnr_sbox_superuser`. Module API: **1**. Repository visibility: private.

The candidate includes console and chat commands, permissions, explicit ownership, moderation, native bindings, module lifecycle, host-local storage and audit. It requires no external runtime service or executable.

Dedicated-client deployment still needs a valid adopting-game package record on the tested engine. Dedicated host/console/restart checks and editor two-client checks passed; this is not a certified multiplayer production release. No package, GitHub release or public tag has been published.

Visual admin UI, voice moderation, player-hosted production and host migration remain deferred. ImGui source has a [staging folder](../dev/ui-source/sbox-imgui/README.md). No redistribution license has been selected.
