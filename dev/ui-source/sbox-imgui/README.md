# Future UI source staging

Place the source supplied from https://github.com/zeljkovranjes/sbox-imgui in this folder.

This is development staging only: it is outside `Code/` and does not compile into the library. Task 1 does not import the UI, add a package dependency or build an administration menu. Before a later UI task, review the upstream license and dependencies, then place only the needed runtime source in the appropriate package layers. The delivered product must remain one s&box library with no external executable or service.

The user selected this UI on 2026-10-17. Its intended operator surface and implementation task remain to be specified; the original specification excluded a visual UI from the first release.
